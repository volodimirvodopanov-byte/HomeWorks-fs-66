# My Library — электронный каталог книг

Учебный проект (ДЗ № 40, группа fs_66). React-приложение, которое показывает
каталог книг библиотеки с разделением по жанрам.

## Возможности

- Общая статистика: всего книг и сколько доступно для выдачи
- Полный каталог книг
- Отдельные разделы по пяти жанрам
- Статус доступности («Доступна» / «Нет в наличии»)
- Отметка «Классическое издание» для книг до 2000 года
- Сообщение, если в категории нет книг

## Технологии

React, Vite, JavaScript (JSX), CSS

## Запуск

```bash
npm install
npm run dev
```

После запуска открыть в браузере адрес, который покажет терминал
(обычно http://localhost:5173).

## Структура компонентов

```
App
 ├── Header
 ├── LibraryStats
 ├── BookList (все книги / по жанру)
 │    └── BookCard
 │         ├── Card
 │         └── AvailabilityBadge
 └── Footer
```

Данные хранятся в `src/data/books.js`. Фильтрация по жанру происходит
внутри `BookList` через пропс `genre`.
